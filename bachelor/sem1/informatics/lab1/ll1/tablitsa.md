# Лабораторная работа №1

**Задание 1**

|Тип|Числитель|Знаменатель|Результат|Вывод|
|:---:|:---:|:---:|:---:|:---:|
|float|64.0000000000|0.0000300000|2133333.5000000000|результат больше точного примерно в 2·10⁶ раз|
|double|0.0000299215|0.0000300000|0.9973843560|около 0.26 %|

Точное значение дроби равно 1: после раскрытия скобок числитель (a+b)³ − (a³+3a²b) равен 3ab² + b³, то есть совпадает со знаменателем. 
  При a = 1000 и b = 0.0001 оба равны 3·10⁻⁵ (точнее, 3.000001·10⁻⁵).
  Знаменатель в обоих типах получился верным (0.00003). Он считается из малых чисел, где вычитания нет, поэтому точность сохраняется.
  Числитель даёт всю погрешность. Величины (a+b)³ и a³+3a²b близки к 10⁹ и отличаются лишь на величину порядка 3·10⁻⁵. 
  При вычитании почти равных чисел старшие цифры сокращаются, а остаются только младшие, в которых накопились ошибки округления. 
  
  Результат float. Тип float хранит около 7 десятичных цифр. 
                   Для чисел порядка 10⁹ расстояние между соседними представимыми значениями равно 64. 
                   Поэтому разность двух таких чисел может быть только кратна 64. 
                   Числитель получился 64 вместо 3·10⁻⁵, и результат 2133333.5 не имеет ничего общего с правильным ответом.

Результат double. Тип double хранит около 15–16 цифр. 
                  Для чисел порядка 10⁹ шаг между соседними значениями около 10⁻⁷, что уже сравнимо с числителем (3·10⁻⁵). 
                  Поэтому числитель 0.0000299215 отличается от точного значения примерно на 0.26 %, и результат 0.99738 близок к 1, но не равен ему.
